# 한국사능력검정시험 심화 학습 사이트

최태성 「한국사능력검정시험 심화」 유튜브 강의를 따라가며 쓰는 정적 학습 사이트입니다.
서버 없이 `index.html` 하나로 동작하고, 그대로 GitHub Pages에 올릴 수 있습니다.

`3r15/my-study`(정보처리산업기사 학습 사이트)의 구조를 따르되, 중복되거나 이 과목에
필요 없는 부분은 덜어 냈습니다. 무엇을 덜어 냈는지는 아래 「my-study와 무엇이 다른가」에 적었습니다.

## 구성

```
history/
├─ index.html            앱 전체 (SPA, 외부 라이브러리 없음)
├─ sw.js                 서비스 워커 — 두 번째 방문부터 오프라인 동작
├─ manifest.webmanifest  홈 화면에 추가하면 앱처럼 실행
├─ icon.svg
├─ data/
│  ├─ index.json         시대 7개 + 차시 40개 정의
│  ├─ concepts-1.json … concepts-7.json   시대별 개념
│  └─ quiz-1.json … quiz-7.json           시대별 문항
└─ build/
   ├─ README.md          자막 수집 → 데이터 반영 절차
   ├─ merge.py           무결성 검사기
   └─ lectures/          로컬에서 수집한 자막 요약을 놓는 자리
```

## 화면

### 1. 홈
푼 문제 수·정답률·학습 완료 개념 수, 시대별 진행 막대, 이어풀기(안 푼 문제 / 랜덤 /
틀린 문제만 / 취약 개념 집중), 지금 약한 개념 목록.

### 2. 개념
시대 → 차시 → 항목 트리입니다. 한 항목이 곧 하나의 개념이고, 네 개의 축으로 걸러 봅니다.

| 축 | 값 |
|---|---|
| 시대 | 선사 · 삼국/남북국 · 고려 · 조선 · 근대 · 일제 강점기 · 현대 |
| 차시 | 1~40강 (강의 링크가 함께 걸립니다) |
| 유형 | 인물 · 사건 · 제도 · 문화 · 사료 · 흐름 |
| 중요도 | 최빈출 · 중요 · 참고 |

항목별로 학습 완료 체크와 메모를 남길 수 있고, **관련 문항으로 양방향 링크**가 걸립니다.
제목·키워드·연도·본문 전문 검색을 지원합니다.

### 3. 문제
시대별 / 차시별 / 개념별 / 랜덤 / 틀린 문제만 / 취약 개념 집중 / 넘긴 문항으로 골라 풉니다.
채점하면 정답과 해설에 더해 **내가 고른 선택지가 어떤 개념의 내용인지**를 짚어 줍니다.

> 광종 문제에서 ②(공민왕의 전민변정도감)를 골랐다
> → "광종을 몰라서"가 아니라 **"광종과 공민왕을 헷갈려서"** 틀렸다고 기록됩니다.

### 4. 오답 분석
- **선택지로 본 오개념** — 취약 개념 점수 순위
- **헷갈린 짝** — 고른 개념 ↔ 정답 개념을 짝으로 묶어 몇 번 헷갈렸는지
- 시대별 정답률, 모르겠음으로 넘긴 문항 다시 풀기

### 5. AI
정적 사이트라 API 키를 넣을 수 없어 **복사 → 붙여넣기 → 결과 JSON 올리기**로 왕복합니다.
프롬프트에는 내 취약 개념·최근 오답·사이트가 쓰는 개념 이름 목록이 함께 담깁니다.

| 갈래 | 결과물 |
|---|---|
| 문제 출제 | 내 취약 개념을 겨냥한 4지선다 10문항 JSON |
| 개념 요약 | 헷갈리는 짝을 구분점과 함께 정리한 노트 JSON |
| 취약점 진단 | 사람이 읽는 진단 글 (무엇을 어떤 순서로 볼지) |

올린 파일은 문항인지 노트인지 자동으로 알아보고, **AI 문항의 풀이 기록은 기출 통계와
분리해서** 저장하므로 정답률이 흐려지지 않습니다.

## 취약 개념이 쌓이는 방식

선택지 하나하나에 그 선택지가 **실제로 설명하는 개념 번호**(`options[].refs`)를
달아 두었습니다. 문제를 틀리면 이렇게 점수가 쌓입니다.

| 신호 | 의미 | 가중치 |
|---|---|---|
| 내가 고른 오답의 `refs` | 이 개념을 **옳다고 착각**했다 | **+3** |
| 정답 선택지의 `refs` | 이 개념을 **몰랐다** | +2 |
| 문항 주제 `refs[0]` | 이 주제가 약하다 | +2 |
| 맞힌 문항의 `refs` | 회복 | −1 |
| 「모르겠음」 누름 | 주제 전체가 약함 | +2 |

"잘못 아는 것"이 "모르는 것"보다 위험하므로 +3이 +2보다 큽니다. 회복(−1)은 한 번
맞혔다고 바로 지워지지 않도록 일부러 느리게 잡았고, 점수는 0 미만으로 내려가지 않습니다.
"옳지 않은 것은?" 같은 부정형 문항에서는 정답 선택지가 곧 틀린 서술이므로 +2를 붙이지 않습니다.

## 데이터 저장

모든 학습 기록은 브라우저 `localStorage`(키 `hist_v1`)에만 저장됩니다. 서버로 보내지 않습니다.

```js
{ answers:{qid:{sel,ok,t,era,lec}},   // 문항별 응답
  weak:{conNo: score},                // 취약 개념 점수
  read:{conNo:1},                     // 학습 완료 표시
  notes:{qid}, conNotes:{conNo},      // 메모
  unknown:[qid],                      // 모르겠음으로 넘긴 문항
  ai:{ sets:[…], qs:[…], ans:{}, notes:{} },  // AI 문항·노트 (통계 분리)
  ver:1 }
```

기기를 옮기거나 초기화하기 전에 **⚙ → 백업 내보내기**로 JSON을 저장하세요.

## 데이터를 더 채우려면

1. 로컬에서 자막을 수집합니다 — [`build/README.md`](build/README.md) 1단계
2. `data/concepts-<시대>.json`과 `data/quiz-<시대>.json`에 개념·문항을 씁니다 — 2단계
3. 검사를 돌립니다 — 오류가 있으면 비0으로 끝납니다

```bash
python3 build/merge.py --write
```

4. 자막을 반영한 차시는 `data/index.json`의 `lectures[].src`를 `"lecture"`로 바꿉니다
5. `sw.js`의 `const V` 값을 올립니다 (안 올리면 옛 캐시가 남습니다)

## 로컬에서 보기

```bash
python3 -m http.server 8000   # 그 뒤 http://localhost:8000
```

> ⚠️ `index.html`을 더블클릭해서 열면 동작하지 않습니다.
> `file://`에서는 브라우저 보안 정책상 `fetch`로 `data/*.json`을 읽을 수 없습니다.
> (이 경우 화면에 안내가 뜹니다.)

## my-study와 무엇이 다른가

| | my-study | history |
|---|---|---|
| 모드 | 필기 / 실기 2모드 | 단일 모드 |
| 탭 | 모드당 5개 (합 10개) | 5개 |
| 데이터 | JSON 24개 + 이미지 294개 (2.8 MB) | JSON 15개 (이미지 없음) |
| 빌드 | PDF 파서 5종 (pdfplumber) | 무결성 검사기 1개 |
| AI 프롬프트 빌더 | 화면마다 하나씩 9벌 | 공통 컨텍스트 + 갈래별 지시문, 1벌 |

**덜어 낸 것** — 실기 모드 전체(원본의 45%), 모의고사 조립, 출제기준 대조, 세트 관리,
HTML 내보내기, 용어사전·신출개념·암기카드 별도 탭(개념 항목 하나에 흡수),
PDF 파싱과 이미지 파이프라인, 미참조 레거시 `v1.html`, 중복 정의된 `hl()`과 `shuffle()`.

**그대로 가져온 것** — 무의존 단일 SPA와 해시 라우터, JSON을 프레임워크 없이 그리는
블록 렌더러, 선택지 `refs` 기반 취약 개념 가중치 모델, localStorage 백업/복원, PWA 3종.
